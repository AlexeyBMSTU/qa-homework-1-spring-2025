### Настройки

URL: https://pushart.online/settings

__Основная информация__

<img width="300" src="https://github.com/user-attachments/assets/b93bfd29-4b94-486d-b752-f1f9a1f9eab9" />

1. Кнопка "Выбрать аватар"
- При нажатии кнопки "Выбрать аватар" открывается окно с возможностью выбрать файл
- При выборе файла с разрешением, отличным от jpg, jpeg, png, высвечивается надпись "Неверный формат файла"
- При выборе файла с разрешением jpg, jpeg, png высвечивается надпись "Аватар успешно применён", аватар меняется

2. Персонализация (имя и почта)
- При вводе логина больше 10 символов выводится сообщение "логин должен быть не более 10 символов"
- При вводе логина согласно [политике валидиации](./validationPolitics.md) логин успешно изменяется
- При неуспешной попытке изменить логин или почту выводится сообщение "Ошибка при сохранении данных"
- При вводе почты в нарушение правил [политики валидиации](./validationPolitics.md) данные сохраняются **БАГ** (добавить обработку инпута почты согласно политике валидации)

__Безопасность__

<img width="300" src="https://github.com/user-attachments/assets/931b075e-0969-4e62-bfad-720c95c56e33" />

- Нажатие на кнопку "Сохранить" при незаполненных полях выводит сообщение "Данные успешно сохранены" **БАГ** (данные не должны сохраняться, сообщение лишнее)
- Нажатие на кнопку "Сохранить" при неправильно заполненном инпуте "Старый пароль" (другие инпуты пустые) выводит сообщение "Данные успешно сохранены" **БАГ** (данные не должны сохраняться, пароль неверный, сообщение лишнее)
- Если ввести верный старый пароль и новый пароль будет совпадать со старым, то выводит сообщение "Данные успешно сохранены" **БАГ** (данные не должны сохраняться, пароль не должен совпадать со старым, сообщение лишнее)
- Если ввести новый пароль менее 8 символов, выводится сообщение "Пароль должен быть минимум 8 символов"
- Если ввести новый пароль без цифры, выводится сообщения "В пароле должна быть одна цифра"
- Если ввести новый пароль без спецсимвола, выводится сообщение "В пароле должен быть один спецсимвол"
- Если ввести новый пароль без заглвной буквы, выводится сообщение "Не хватает: большой и маленькой буквы"
- Если инпут "Придумайте новый пароль" не совпадает с инпутом "Повторите пароль", выводится сообщение "Пароли должны совпадать"

### Просмотр медиа-контента у постов

URL: https://pushart.online/profile/

**Нажать на медиа-контент**

- Если контент - это видео, то открывает видео-плеер, с возможностью ускорить, замедлить, перематать видео, а так же уменьшить или увеличить скорость.
- Если контент - pdf-файл, файл открывается в отдельном окне.
- Если контент - музыка, то открывается в этом же окне плеер, с возможностью перематать, увеличить или уменьшить звук.
- Если контентов несколько в одном посте еще и разных, то справа и слева есть кнопки для перехода.

### Лента модератора
URL: https://pushart.online/moderation

![Снимок экрана в 2025-03-20 11-08-00](https://github.com/user-attachments/assets/944cd3d0-d9ee-467e-9814-a1a076a3b362)

- При нажатии на кнопку "Опубликованные" выведутся все недавно опубликованные посты
- При нажатии на кнопку "Жалобы" выведутся все посты: на которых пожаловались пользователи
- При нажатии на имя пользователя происходит редирект на профиль
- При нажатии на аватарку полдьзователя, аватарка открывается на весь экран

- При нажатии на кнорпку "Заблокировать" пост блокируется и его не смогут видеть пользователи
